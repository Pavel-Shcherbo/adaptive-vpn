## Обзор проекта

Этот проект представляет собой адаптивную VPN систему, которая автоматически переключается между протоколами WireGuard и IPsec на основе метрик сети (пинг, джиттер, полоса пропускания). Система также использует:
- Криптографию на эллиптических кривых Curve25519 для обмена ключами
- Пост-квантовую криптографию (алгоритм Kyber) для повышенной безопасности
- Автоматическую адаптацию к условиям сети

## Настройка сервера

### Информация о сервере
- IP-адрес: 37.220.82.110
- Доступ: SSH как пользователь root
- Закрытые порты: 587, 3389, 389, 53413, 465, 25, 2525

### Подготовка сервера

1. Подключитесь к серверу по SSH:
   ```bash
   ssh root@37.220.82.110
   ```

2. После входа на сервер выполните установку необходимых пакетов:
   ```bash
   apt update && apt upgrade -y
   apt install -y python3 python3-pip python3-venv wireguard strongswan iptables-persistent openssl nginx cmake gcc ninja-build libssl-dev python3-dev
   ```

3. Создайте необходимые директории и настройте брандмауэр:
   ```bash
   mkdir -p /opt/adaptive-vpn
   mkdir -p /etc/adaptive-vpn/clients
   mkdir -p /etc/adaptive-vpn/kyber_keys
   mkdir -p /etc/ipsec.d/connections
   
   # Разрешите порты для WireGuard, IPsec и API
   ufw allow 51820/udp  # WireGuard
   ufw allow 500/udp    # IPsec IKE
   ufw allow 4500/udp   # IPsec NAT-T
   ufw allow 8443/tcp   # API сервер
   ufw enable
   
   # Включите IP forwarding
   echo "net.ipv4.ip_forward=1" > /etc/sysctl.d/99-vpn.conf
   sysctl -p /etc/sysctl.d/99-vpn.conf
   
   # Настройте masquerading
   iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
   netfilter-persistent save
   ```

4. Загрузите проект в каталог сервера:
   ```bash
   cd /opt/adaptive-vpn
   
   # Если у вас есть Git-репозиторий проекта
   git clone https://your-repository-url.git .
   
   # Или загрузите файлы вручную
   # (используйте SCP или аналогичный инструмент для копирования файлов на сервер)
   ```

5. Настройте виртуальное окружение и установите зависимости:
   ```bash
   cd /opt/adaptive-vpn
   python3 -m venv venv
   venv/bin/pip install -r server/requirements.txt
   venv/bin/pip install liboqs-python
   
   # Копируем файл сервера
   cp server/vpn_server.py /opt/adaptive-vpn/
   ```

6. Настройте systemd-сервис:
   ```bash
   cp scripts/vpn-server.service /etc/systemd/system/
   systemctl daemon-reload
   systemctl enable vpn-server
   systemctl start vpn-server
   ```

7. Настройте Nginx для HTTPS:
   ```bash
   cat > /etc/nginx/sites-available/vpn-api << 'EOL'
   server {
       listen 80;
       server_name _;

       location / {
           return 301 https://$host$request_uri;
       }
   }
   
   server {
       listen 443 ssl;
       server_name _;
       
       ssl_certificate /etc/adaptive-vpn/cert.pem;
       ssl_certificate_key /etc/adaptive-vpn/key.pem;
       
       location / {
           proxy_pass http://localhost:8000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }
   EOL
   
   ln -sf /etc/nginx/sites-available/vpn-api /etc/nginx/sites-enabled/
   rm -f /etc/nginx/sites-enabled/default
   
   # Генерируем SSL-сертификат
   mkdir -p /etc/adaptive-vpn
   openssl req -x509 -newkey rsa:4096 -nodes \
       -keyout /etc/adaptive-vpn/key.pem \
       -out /etc/adaptive-vpn/cert.pem \
       -days 365 -subj "/CN=adaptivevpn.local"
       
   systemctl restart nginx
   ```

8. Запустите StrongSwan (IPsec):
   ```bash
   systemctl enable strongswan
   systemctl start strongswan
   ```

9. Проверьте статус служб:
   ```bash
   systemctl status vpn-server
   systemctl status strongswan
   systemctl status nginx
   ```

## Настройка клиента

### Установка необходимых программ

1. Установите Python 3.6 или выше и зависимости:
   
   **Windows:**
   ```powershell
   # Установите Python с https://www.python.org/downloads/
   # Затем установите зависимости проекта
   pip install -r client/requirements.txt
   pip install liboqs-python
   ```

   **Linux/macOS:**
   ```bash
   # В Ubuntu/Debian
   sudo apt install python3 python3-pip
   pip3 install -r client/requirements.txt
   pip3 install liboqs-python
   ```

2. Установите необходимые VPN-клиенты:
   
   **Windows:**
   - [WireGuard для Windows](https://www.wireguard.com/install/)
   - IPsec: встроенный VPN-клиент Windows или StrongSwan VPN Client

   **Linux:**
   ```bash
   sudo apt install wireguard strongswan
   ```

   **macOS:**
   ```bash
   brew install wireguard-tools
   # IPsec использует встроенный VPN-клиент
   ```

## Тестирование

### Запуск клиента

1. Запустите клиент VPN:
   ```bash
   # На Windows
   python client/vpn_client.py --action start
   
   # На Linux/macOS
   python3 client/vpn_client.py --action start
   ```

   Клиент выполнит следующие действия:
   - Генерация ключей Curve25519 и Kyber
   - Регистрация на сервере
   - Получение конфигураций для WireGuard и IPsec
   - Измерение сетевых метрик для выбора оптимального протокола
   - Запуск выбранного VPN-протокола

2. Проверка статуса клиента:
   ```bash
   python client/vpn_client.py --action status
   ```

3. Остановка клиента:
   ```bash
   python client/vpn_client.py --action stop
   ```

### Тестирование производительности

1. После подключения проверьте работоспособность VPN:
   ```bash
   ping 8.8.8.8
   curl ifconfig.me  # Должен отображаться IP вашего VPN-сервера
   ```

2. Для имитации различных сетевых условий можно использовать утилиты:
   
   **Linux:**
   ```bash
   # Имитация высокого пинга (задержка 100мс)
   sudo tc qdisc add dev eth0 root netem delay 100ms
   
   # Имитация нестабильного соединения (10% потерь пакетов)
   sudo tc qdisc add dev eth0 root netem loss 10%
   
   # Сброс настроек
   sudo tc qdisc del dev eth0 root
   ```

3. Наблюдайте за логами клиента, чтобы видеть переключение между протоколами:
   ```bash
   # Установите более короткий интервал для тестирования
   python client/vpn_client.py --action start --interval 30
   ```

## Устранение неисправностей

### Проблемы с сервером

1. Проверьте логи сервера:
   ```bash
   tail -f /var/log/vpn-server.log
   ```

2. Проверьте статус служб:
   ```bash
   systemctl status vpn-server
   systemctl status strongswan
   ```

3. Проверьте открытые порты:
   ```bash
   ss -tulpn | grep -E '(8443|51820|500|4500)'
   ```

4. Проверьте правила брандмауэра:
   ```bash
   ufw status
   iptables -L -v
   iptables -t nat -L -v
   ```

### Проблемы с клиентом

1. Проверьте логи клиента (выводятся в stdout)

2. Проверьте статус локальных VPN-соединений:
   
   **Windows (WireGuard):**
   ```powershell
   Get-Service WireGuardTunnel*
   ```

   **Linux (WireGuard):**
   ```bash
   sudo wg show
   ```

   **IPsec на Linux:**
   ```bash
   sudo ipsec status
   ```

3. Проверьте файлы конфигурации:
   ```bash
   # Файлы сохраняются в ~/.adaptive-vpn/
   ls -la ~/.adaptive-vpn/
   ```

### Общие рекомендации

- В случае проблем с регистрацией клиента, удалите существующие файлы сессии и ключей:
  ```bash
  rm -rf ~/.adaptive-vpn/session_id ~/.adaptive-vpn/client_*key* ~/.adaptive-vpn/kyber_keys/
  ```

- Убедитесь, что порт 8443 доступен на сервере и не заблокирован промежуточными брандмауэрами

- При проблемах с Kyber, проверьте правильность установки liboqs-python:
  ```bash
  pip show liboqs-python
  ```
